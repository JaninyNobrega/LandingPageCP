# 🩺 Landing Page — Dr. Rafael Montenegro

Projeto acadêmico desenvolvido como **Produção Textual Individual (PTI)** para a disciplina de **Fundamentos de Programação Web**, do curso de **Análise e Desenvolvimento de Sistemas — Senac EAD**.

O projeto consiste no desenvolvimento de uma **Landing Page responsiva para um profissional autônomo**, aplicando os conceitos estudados durante a disciplina.

> **Importante:** Dr. Rafael Montenegro é um personagem fictício criado exclusivamente para fins acadêmicos. As informações, imagens, contatos e dados apresentados no projeto não correspondem a um profissional ou clínica real.

---

## 📚 Sobre a atividade

A proposta da atividade consiste em selecionar um ramo de negócio de pequeno porte ou profissional autônomo e desenvolver uma Landing Page para apresentação de seus serviços.

Para este projeto foi escolhido o segmento de **Cirurgia Plástica e Estética**, criando a identidade fictícia:

**Dr. Rafael Montenegro — Cirurgia Plástica & Estética Avançada**

A página foi desenvolvida buscando unir os requisitos técnicos da atividade a uma identidade visual sofisticada, inspirada em sites contemporâneos de clínicas e profissionais da área de cirurgia plástica e estética.

---

## 🎯 Objetivo

Desenvolver uma página web capaz de apresentar o profissional e seus serviços de maneira clara, atrativa e organizada, contendo diferentes seções de conteúdo e uma chamada para contato.

O projeto também tem como objetivo aplicar conceitos fundamentais de desenvolvimento web, especialmente:

- Estruturação semântica utilizando HTML;
- Estilização com CSS;
- Organização de layouts com Flexbox;
- Responsividade para diferentes tamanhos de tela;
- Hierarquia visual;
- Navegação por âncoras;
- Formulários HTML;
- Validação nativa de campos;
- Organização de arquivos e assets.

---

## 🖥️ Seções da Landing Page

A página é composta pelas seguintes áreas:

### Hero
Apresentação principal do profissional e chamada para agendamento de consulta.

### Sobre
Apresentação do Dr. Rafael Montenegro e da proposta de atendimento personalizado.

### Procedimentos
Apresentação das principais categorias de procedimentos:

- Face;
- Mamas;
- Corpo;
- Estética.

### Filosofia
Seção dedicada ao conceito de naturalidade e preservação da identidade do paciente.

### Experiência Montenegro
Apresentação dos principais diferenciais do atendimento:

- Escuta individual;
- Planejamento personalizado;
- Naturalidade;
- Acompanhamento.

### Clínica
Apresentação visual do ambiente fictício da clínica e de sua proposta de conforto, privacidade e atendimento.

### Contato
Formulário para solicitação de atendimento, contendo campos para nome, e-mail, telefone, procedimento de interesse e mensagem.

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais da Web:

- **HTML5**
- **CSS3**
- **Flexbox**
- **Media Queries**
- **Google Fonts**

Não foram utilizados frameworks CSS ou bibliotecas JavaScript, mantendo a implementação alinhada à proposta da disciplina.

---

## 📱 Responsividade

A Landing Page foi desenvolvida para se adaptar a diferentes tamanhos de tela.

Foram utilizadas **Media Queries** para reorganizar elementos, textos, imagens, cards, formulário e navegação em dispositivos com telas menores.

O projeto contempla visualização em:

- Desktop;
- Tablet;
- Smartphone.

---

## 🎨 Identidade visual

A interface utiliza uma proposta visual inspirada no segmento premium de cirurgia plástica e estética.

A identidade foi construída utilizando:

- Tons de marfim e off-white;
- Preto e grafite;
- Detalhes em champagne;
- Tipografia serifada para títulos;
- Tipografia sans-serif para textos;
- Fotografias em estilo editorial;
- Espaçamento amplo e composição minimalista.

### Tipografia

Foram utilizadas as fontes:

- **Cormorant Garamond** — títulos e elementos editoriais;
- **Montserrat** — textos, navegação e formulários.

As fontes são carregadas através do Google Fonts.

---

### 📋 Formulário

O formulário utiliza recursos nativos do HTML para validação dos campos obrigatórios.

Por se tratar de um projeto acadêmico exclusivamente Front-End, o formulário não realiza o envio real de informações para servidor, banco de dados ou e-mail.

A confirmação apresentada na interface possui finalidade demonstrativa.
---
### ▶️ Como executar o projeto
Faça o download ou clone este repositório.
Abra a pasta do projeto no Visual Studio Code.
Abra o arquivo index.html diretamente no navegador.

Também é possível utilizar a extensão Live Server do Visual Studio Code para executar o projeto localmente.
